# Google Play Store Analytics Dashboard – Tableau

## Project Overview

This project focuses on analyzing Google Play Store application data using **Tableau Public**. The objective is to explore application performance, installation trends, category popularity, content ratings, pricing models, and app updates through interactive data visualizations.

The project transforms raw application data into meaningful insights to support business understanding and data-driven decision-making.

## Business Problem

The objective of this project is to analyze Google Play Store applications and answer key business questions:

- Which app categories have the highest number of installs?
- How many applications are updated over time?
- Which content-rating groups receive the highest installs?
- What is the distribution of free and paid applications?
- Which five applications have the highest number of installs?

## Dataset Information

- **Dataset:** Google Play Store Dataset
- **File Name:** googleplaystore_clean.xlsx

## Dashboard Worksheets and Visualizations

### 1. Top 10 Categories by Installs

A horizontal bar chart showing the top 10 application categories based on total installs.

**Purpose:**
- Identify the most popular app categories.
- Compare installation performance across categories.
- Understand user preferences.

### 2. App Updates by Month

A line chart displaying the number of application records across update months.

**Purpose:**
- Analyze app update patterns over time.
- Identify periods with increased update activity.
- Understand update trends.

### 3. Installs by Content Rating

A bar chart comparing total installs across different content-rating categories.

**Purpose:**
- Understand installation distribution by content rating.
- Identify which rating groups attract more installs.

### 4. Free vs Paid Apps

A pie chart comparing the distribution of free and paid applications.

**Purpose:**
- Understand the pricing structure of applications.
- Compare free and paid app distribution.

### 5. Top 5 Apps by Installs

A bar chart identifying the five applications with the highest total installs.

**Purpose:**
- Identify the most popular applications.
- Compare installation performance among leading apps.

## Project Workflow

1. Connected the cleaned Excel dataset to Tableau Public.
2. Explored the dataset and verified the available fields.
3. Created individual worksheets for each analytical requirement.
4. Used dimensions and measures to build visualizations.
5. Applied sorting and Top N filters.
6. Added data labels and formatted chart colours.
7. Created a dashboard.
8. Combined all five worksheets into one dashboard.
9. Added a dashboard title and arranged the visualizations.
